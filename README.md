# cutemoji

A responsive, multilingual emoticon web app by thenovary.

Live: https://thenovary.github.io/cutemoji/

## Local preview

Run `python3 -m http.server 4173` from this directory.

## GitHub Pages

Publish from the `main` branch, `/ (root)` folder. No build step is required.

Translations are in `locales/`. Support links are in `site-config.js`.
MY items, favorites and recent history stay in the user’s browser. Use backup export/import to move them between browsers or devices.

Ads are not enabled. Ad previews only appear on localhost with `?previewAds=1`.
