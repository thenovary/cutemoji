이 브라우저에 저장하는 내용

큐트모지는 회원가입을 요구하지 않습니다. MY 이모티콘, 즐겨찾기, 최근 복사 기록과 선택 언어는 현재 브라우저의 localStorage에 저장합니다. 웹앱 자체는 이 항목들을 운영자 서버에 전송하지 않습니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있으며, 삭제한 항목은 백업이 없으면 복구할 수 없습니다.

백업 파일과 클립보드

백업 내보내기는 MY·즐겨찾기·최근 사용을 JSON 파일로 저장합니다. 백업 가져오기는 선택한 파일을 브라우저 안에서 읽어 합칩니다. 파일에 개인적인 내용이 있을 수 있으므로 공유할 때 주의하세요. 복사 버튼은 선택한 이모티콘이나 계좌번호를 클립보드에 쓰며, 기존 클립보드 내용을 수집하지 않습니다.

호스팅과 오프라인 저장

이 웹앱은 GitHub Pages로 제공됩니다. 접속 요청을 처리하는 과정에서 GitHub가 IP 주소 등 접속 정보를 처리할 수 있습니다. 브라우저는 화면·번역·아이콘 같은 앱 파일을 Cache Storage에 저장할 수 있습니다. 호스팅 제공자의 처리는 GitHub 개인정보처리방침을 따릅니다.

이메일 문의

메일을 보내면 회신 주소와 문의 내용을 전달받습니다. 문의 대응을 위해 사용하며, 처리 후 더 이상 필요하지 않은 정보는 삭제합니다. 법령상 보관 의무가 있으면 해당 의무를 따릅니다. 민감한 개인정보는 보내지 마세요.

외부 후원 서비스

후원 버튼을 누르면 Buy Me a Coffee, 카카오페이 또는 토스로 이동합니다. 해당 서비스의 결제·송금·개인정보 처리는 각 제공자의 정책을 따릅니다. 큐트모지는 카드번호나 결제 비밀번호를 입력받지 않습니다. 토스 송금 링크에는 공개된 수취 계좌 정보가 포함됩니다.

광고 및 쿠키

현재 큐트모지에서는 Google 광고를 요청하지 않습니다. 애드센스 사이트 확인을 위한 게시자 정보만 포함되어 있습니다. 광고를 활성화할 경우 이 안내를 갱신하고 적용 지역에 필요한 동의 절차를 마련합니다.

광고 도입 시 알아둘 사항

Google을 포함한 제3자 광고 제공업체는 이 사이트 또는 다른 사이트의 이전 방문을 바탕으로 광고를 제공하기 위해 쿠키를 사용할 수 있습니다. Google과 파트너는 광고 쿠키를 이용해 개인 맞춤 광고를 제공할 수 있습니다. Google 광고 설정에서 개인 맞춤 광고 설정을 관리할 수 있습니다. 광고를 활성화하기 전 실제 사용 업체와 동의·설정 방법을 이 페이지에 반영합니다.
